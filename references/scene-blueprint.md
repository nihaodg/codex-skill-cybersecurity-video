# Scene Blueprint

Use a scene table before building the final timeline.

## Recommended fields

- `id`
- `purpose`
- `visual treatment`
- `on-screen text`
- `narration`
- `subtitle chunks`
- `lead_in_frames`
- `tail_frames`

## Good default structure

1. Opening hook
2. Background or setup
3. Development scene A
4. Development scene B
5. Present-day relevance or climax
6. Closing takeaway

## Narration rules

- Keep one core idea per scene.
- Prefer one audio file per scene.
- If a scene narration is too long, split the scene before rendering.
- Let measured audio length drive scene duration.

## Subtitle rules

- Keep subtitles to two lines max.
- Avoid giant paragraph blocks.
- Break on phrase boundaries, not arbitrary character counts.
- Keep subtitle text aligned with the spoken version.

## Competition-style guidance

- Use the first 3 seconds for impact.
- Use the ending for a memorable line, slogan, or call to action.
- Give the last scene a visible hold so the ending can land.
