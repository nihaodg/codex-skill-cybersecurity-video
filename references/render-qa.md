# Render QA

## Sync diagnosis

If narration starts too early:

- increase scene lead-in
- shorten the visual prelude
- move the audio start later for that scene only

If narration ends after the scene cuts:

- extend the scene
- split the narration into two scenes
- reduce visual overload so less setup time is needed

If subtitles feel late or early:

- regenerate them from the same scene narration source
- avoid editing subtitle wording independently unless necessary

## Visual diagnosis

If scenes feel repetitive:

- change the layout, not just the wording
- alternate between large typography, cards, timelines, and centered scenes

If text feels crowded:

- shorten copy
- increase line breaks
- move detail into narration instead of the screen

## Audio diagnosis

If the music masks speech:

- lower the bed level
- fade music under narration
- avoid adding more layers before fixing clarity

## Final verification

- inspect multiple preview frames
- inspect at least one preview video
- probe the final file for stream presence and duration when possible
